The module's path is `app`. Write a package `units` (in the directory `units/`) with
conversions from Celsius to Fahrenheit and back, and a package `stats` (in `stats/`) with the
mean and the maximum of a slice of `float64`. The main package imports both.

Convert the readings 68.0, 75.2, 59.0, 82.4 and 71.6 °F to Celsius and print each, then print
the mean and the maximum in Celsius, and finally 37 °C in Fahrenheit, all to one decimal.

The program must print exactly:

```
68.0°F = 20.0°C
75.2°F = 24.0°C
59.0°F = 15.0°C
82.4°F = 28.0°C
71.6°F = 22.0°C
mean: 21.8°C
max: 28.0°C
body temperature: 98.6°F
```
