Write `fizzbuzz(n)`, which returns "Fizz" for multiples of 3, "Buzz" for multiples of 5,
"FizzBuzz" for multiples of both, and the number itself otherwise. Add Lyth tests for it, at
least four test functions covering plain numbers, Fizz, Buzz and FizzBuzz, and make sure
`lyth test` passes. `main` prints the results for 1 to 15 on one line, separated by spaces.

The program must print exactly:

```
1 2 Fizz 4 Buzz Fizz 7 8 Fizz Buzz 11 Fizz 13 14 FizzBuzz
```
